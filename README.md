# AI Portfolio

Portfólio premium para Technical Lead em **AI Engineering** e **Full Stack Systems**.

## Stack

- Next.js 15+ / React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Shadcn/UI (primitives)
- React Three Fiber

## Quick Start

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Personalização

Edite `src/lib/site-config.ts` — nome, links, métricas, case studies e navegação.
